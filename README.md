# Loop Lariat
A rootin'-tootin' block-puzzle game I made for the 2026 Falling Block Jam. A good example of my cross-platform bindings, to write a game for both Playdate and PCs (via LÖVE2D) from one single codebase. I can't guarantee any good-practice code in here, but feel free to take a look around!

A full list of credits and dependencies can be found [here](https://rae.wtf/manuals/loop-lariat#credits).

If you wanna play this game, it's available for download [here](https://raewtf.itch.io/loop-lariat). Or, if you just LOVE command line tools, use `pdc` to build the `source/` folder, and enjoy!
